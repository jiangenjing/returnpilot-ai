## 口径与免责说明 / Caliber & Disclaimer

- 财务测算为**独立经营情景模型**：结构比例参考中国公开数据，成本水平采用沙特本地口径；非沙特行业均值。
  *Financial figures are an **independent scenario model**: structural ratios reference public China data, cost levels use Saudi figures; not Saudi averages.*
- 标注 **"估算 / 待核实"** 的数字（分品类退货率、单件退货成本、残值率）需通过客户 / 物流 / 险企访谈验证。
  *Items marked **"estimated/to verify"** (category return rates, per-return cost, residual value) require interviews.*
- 两类规模模型：**单商家基准盘（月 1,000 单）** 用于财务；**规模演示盘（月 100k 级）** 仅用于看板并标注"演示数据"。
  *Two scale models: the **single-merchant base case (1,000/mo)** for finance; the **demo scale (100k/mo)** only for dashboards, labeled "demo data."*
